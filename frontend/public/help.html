Genesis Help

Build and try a small app using your connected HighLevel account.

1. Connect your CRM

  1. Sign in to Genesis and select Connect on the projects page.
  2. Authorize the Marketplace app and select the HighLevel location you want to use.
  3. Return to Genesis and confirm that the connection shows as connected.

The account needs access to the selected location and the requested API permissions.

2. Build and refine an app

  1. Create a project and describe what you want in the build conversation. For example: “Build a recent contacts dashboard with search.”
  2. Select Generate. Output appears as it is received; generation can take time. Use Stop to cancel.
  3. Try the app in the live preview. Ask for a change in the conversation to refine it.

If generation stops or reports invalid files, review the saved files and try a more specific request. Provider limits may also require waiting before trying again.

3. Edit, save and review history

  1. Select a file in the explorer and edit it in the code panel. Select Save after making changes.
  2. Open History to review snapshots. Select a version’s comparison option to see its changes, or Restore to replace the current files with that version.

Comparisons are available for generation snapshots with a recorded baseline. Save current edits before generating or restoring.

4. Use CRM features in the preview

Ask for contacts, conversations, messages, calendars, appointments or availability. Supported changes such as creating or updating a contact and sending a message require confirmation in Genesis. Check the details before confirming.

A successful send request does not guarantee delivery. Check the message status in HighLevel. Results and available operations depend on the connected account, permissions and generated app.

Troubleshooting

  • CRM data is missing: check the connected location, permissions and any date or search filters.
  • A change is not visible: reload the data in the generated app and check the record in HighLevel. Some results can take time to update.
  • Preview does not work: inspect the generated files and request a focused correction. The sandbox supports local HTML, CSS and JavaScript and restricts external resources.
  • Generation is limited: wait for the displayed limit window to reset; the AI provider can have separate limits.
